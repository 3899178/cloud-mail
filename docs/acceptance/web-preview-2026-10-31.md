## 原站保留功能的网页检查

在独立的本机 Worker、D1、KV 和虚构账号上，当前源码与相同前端构建已经观察到：

- 两位用户各自保存、重新加载自己的草稿，用户切换后内容保持隔离；删除一位用户的测试草稿不影响另一位，最后只清理了测试草稿。
- 标题搜索从 61 封人工邮件中找到唯一目标，详情显示匹配的发件人、标题及正文。
- 收藏进入原星标列表，全页刷新后保留；普通用户看不到管理员的收藏，管理员重新登录仍能看到；取消本次新增收藏后列表为空。
- 普通用户的原功能菜单不显示管理员入口。菜单检查不替代直接接口和路由权限检查。
- 外部同步服务不可用时明确显示 `SYNC_UNAVAILABLE`，上述原站操作仍可使用。

这些是有限的实际网页场景。原有收发、附件、搜索、权限、邀请码、统计、推送、可选 AI 和公开 API 的完整验收清单仍须逐项完成；路由存在和单元测试通过不能代替功能验收。
